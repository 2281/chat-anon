# AGENTS.md

Файл для ИИ-агентов, работающих с этим проектом. Читатель файла ничего не знает о проекте.

## Обзор проекта

**chat-anon** — анонимный чат без регистрации. На данный момент проект находится на стадии концепта: в репозитории есть только `README.md` с описанием идеи, кода, конфигурации и инфраструктуры нет. Git-репозиторий ещё не инициализирован.

Исходное описание (на русском) находится в `README.md` — это главный и единственный источник требований.

## Функциональные требования (из README.md)

- Пользователь заходит на страницу чата без регистрации.
- Никнейм необязателен; если не введён, назначается `анон-<случайное число>` (например `анон-1231245`).
- Все пользователи видят все сообщения всех пользователей чата.
- В чат можно отправлять: текст, фото, видео, аудио, эмодзи. Лимит загружаемого файла — 100 МБ.
- На сообщения можно ставить лайки и дизлайки.
- Поддерживаются ответы на сообщения и цитирование (всего сообщения или его части).
- Нужна антиспам-защита от зловредного спама (по README это требует отдельной проработки и предложений — механизм ещё не выбран).
- Интерфейс — простой, минималистичный, в стиле пиксель-арт, с подходящим под стиль шрифтом.
- Сообщениям автоматически присваиваются темы в виде хэштегов; по клику на хэштег можно найти все сообщения по теме.
- Нужна кнопка «читать ветку»: просмотр нити сообщений по диалогу/обсуждению за короткий период (час, день, неделя и т.п.).

## Целевой технологический стек (заявлен в README.md)

- **Бэкенд:** Python (конкретный фреймворк не выбран).
- **База данных:** PostgreSQL — все сообщения.
- **Файловое хранилище:** S3-совместимое хранилище (типа MinIO) — все файлы.
- **Фронтенд:** инструменты не выбраны — нужен простой современный минималистичный интерфейс в стиле пиксель-арт с подходящим шрифтом.

Всё, что не перечислено выше (фреймворки, ORM, транспорт реального времени, сборщик фронтенда, тестовые фреймворки, деплой), на момент написания файла **не решено** и в репозитории не зафиксировано. Не выдумывайте решения — если выбор нужен, предлагайте его явно и отделяйте от фактов.
