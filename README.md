## Это проект чата, где можно анонимно писать что угодно без регистрации 
Общий сценарий взаимодействия пользователя: Пользователь заходит на страницу чата, никакой регистрации не требуется, пользователь может ввести какой-нибудь никнейм, а может не вводить, по умолчанию он "анон-1231245" (где 1231245 - случайно присваиваемое число, если пользователь не ввёл никнейм)
все видят все сообщения, отправленные всеми пользователями в этот чат. Есть поле ввода текста, можно отправлять 
что угодно - текст, фото, видео, аудио (ограничение загружаемого файла до 100 мегабайт), эмодзи, ставить лайки, 
дизлайки сообщениям, отвечать на сообщения, цитировать всё сообщение или его часть. 
Должна быть антиспам защита, чтобы пользователь не мог зловредно спамить в чат (по поводу этого нужна отдельная проработка и предложения)
Интерфейс должен быть простой минималистичный, можно что-то в стиле пиксель арт, шрифт соответственно подходящий по стилю.
Сообщениям должны автоматически присваиваться темы в виде хэш тегов, чтобы при необходимости можно было нажать на хэш тег и поискать все сообщения, относящиеся к теме, так же нужно сделать чтобы была кнопка "читать ветку" чтобы можно
было прочитать нить сообщений, относящихся к диалогу или обсуждению какой-то темы за короткий промежуток времени 
(день, час, неделя итд).
Код можно написать на python для бэкенда. Для фронтенда выбрать наиболее подходящие инструменты для реализации
 простого современного минималистичного интерфейса что-то в стиле пиксель арт, шрифт соответственно подходящий по стилю. Все сообщения хранятся в БД Postgres, все файлы в S3 хранилище типа Minio
